## Project Topic: E commerce Sales Analysis

### Project Overview

This Data Analysis project aims to generate insight into the sale performance of the E commerce project over the past year. By analyzing the various parameters in the Data, we received to gather enough insight to make reasonable decision.

This documentation will enable us to make better decisions and tell a compelling story.

### Data Source

The primary source of Data used here is Sales.csv and this is an open-source data that can be freely downloaded from an open source online such as Kaggle or FRED or any other data repository site.
